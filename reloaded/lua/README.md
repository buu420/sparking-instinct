# Lua reader on Reloaded II

The native host loads the existing 24 Lua modules from `Scripts`. It embeds Lua 5.4.7, preloads the Prism bridge as `speech_bridge`, and opens the existing `audio_bridge.dll` from `Scripts`. `AudioDescription` stays beside that audio bridge so its relative WAV paths resolve. The adapter reads the Windows x64 Steam build 24953175, executable SHA-256 `6DB7002A8FA66A1309B01037D8A9A8C678A8ECD35B72D4C6AFAC550A74371657`.

## What the Lua modules use

- `main`, `game_thread`, `helpers`, and `focus_reader` need one persistent game-thread callback, pre/post map-transition delivery, exact widget paths, bounded object lookups, and F3–F9 registration with foreground edge detection. Do not invoke readers while the old world is tearing down or resume from a missed frame by replaying pending announcements. The old team `SetText` hook is dead code in the current reader. `main` obtains team names from displayed portraits and native name records.
- `visible_ui`, `widget_reader`, `poll_trackers`, `skill_list`, `shop`, `episode_battle`, `screen_reader`, and `training_reader` read attached viewport roots, `WidgetTree.RootWidget`, panel children, focus, visibility, opacity, switcher selection, cached geometry, and visible text. They depend on working `IsVisible`, `HasKeyboardFocus`, `HasFocusedDescendants`, `IsInViewport`, `GetParent`, `GetChildrenCount`, `GetChildAt`, `GetChildIndex`, `GetActiveWidget`, and `GetActiveWidgetIndex`. `GetText():ToString()` must return current Unicode text for both plain and rich text. The reader preserves in-game rich-text icon markup until `icon_parser` translates it.
- `language_options`, `team_overview`, `chara_roster`, and `chara_names` read visible image brushes and localized name records. `FindObjects(1, 'SSCharacterDataAsset', shortName, 0, 0, false)` reads a currently loaded asset, with an exact path lookup and the existing local name table as fallbacks. The displayed portrait determines the lookup ID. `Brush.ResourceObject` and `CharacterDataAssetRecord.NameInfo.ShortName/TitleName` are nested reflected properties.
- `battle` reads `AController::GetViewTarget`, controller pawn and `TargetPawn` ownership, and visible player/opponent HP, ki, Sparking, skill points, combo, timers, and result text. The ki guide checks `GetSkillGuideSetOfPlayer(int32)`, `IsBattleKeyPressed(11)`, and `GetBattleKeyHoldTime(11)` after the visible HUD context exists. Any unknown P2 target preserves the baseline and never falls back to player one.
- `movie_reader`, `audio_description`, and `description_manifest` match a visible `SSCriMediaPlayer` material, read `ManaComponents` and the selected source's `VideoTracks`, and time the same existing audio clips with `GetFrameNumber`, `GetStatus`, `IsPlaying`, `IsPaused`, and source URL. Arrays use `GetArrayNum` and one-based bounds, with a ceiling of 16 reads for movie components and tracks. Loss of source, visibility, or clock stops the cue.
- `subtitle_speech` retains the broad automatic subtitle preference on F9, while F6–F8 retain manual screen review. `speech` forwards interrupt and queued requests to the registered Prism bridge. `debug_tools` enables explicit F3/F4/F5 logging. Rich diagnostic property dumps use optional reflection methods and array iteration, and a missing diagnostic field is recorded as unavailable.

## Runtime boundary

- `FindAllOf`, `FindFirstOf`, `FindObjects`, and `StaticFindObject` return validated handles to already loaded objects. No asset loading is necessary. `FindObjects(maxCount, class, name, requiredFlags, excludedFlags, exactClass)` accepts nil name, with zero count meaning unbounded within its verified object query. Static class and default object paths are `/Script/UMG.UserWidget`, `/Script/UMG.Default__WidgetBlueprintLibrary`, and `/Script/UMG.Default__SlateBlueprintLibrary`.
- Handles provide `IsValid`, `IsA`, `GetFullName`, `GetFName`, `GetOuter`, and `type` with equality by live identity. Preserve the package separator and the colon after the first object below it. The title path observed in the installed build has the form `WBP_GRP_Title_CI_Logo_C /Engine/Transient.GameEngine_…:BP_SSGameInstance_C_….WBP_GRP_Title_CI_Logo_C_…`. The readers use that path to identify owned and current widgets. Strings and numbers are copied into Lua. Struct and array views must stay tied to their valid owner and frame.
- `GetAllWidgetsOfClass` copies the output into the passed Lua table with one-based, live `UObject` handles. The reader accepts the array directly or under `FoundWidgets`. With `TopLevelOnly` true it requests viewport roots and independently rechecks `IsInViewport`. Release engine allocations after copying output and use the existing read-cycle cache. The older UE4SS implementation retained `FoundWidgets` tables and native allocations, which is part of the reason this compatibility boundary needs its own tests. [Epic Get All Widgets of Class](https://dev.epicgames.com/documentation/unreal-engine/BlueprintAPI/Widget/GetAllWidgetsOfClass)
- `GetCachedGeometry` returns a 64-byte value. `GetAbsoluteSize` and `LocalToAbsolute` take the snapshot as a const input and return double-precision `FVector2D`. The Lua reader passes `{X = 0, Y = 0}` as the local coordinate. Geometry must remain valid through the current capture. Do not reuse a temporary ProcessEvent parameter pointer in a later call. [Epic Slate Blueprint Library](https://dev.epicgames.com/documentation/unreal-engine/API/Runtime/UMG/USlateBlueprintLibrary)
- `InstallOwnedFiles` exposes `SparkingOpenDataFile(path, mode)` before Lua modules load. It resolves only the subtitle preference and reader-owned debug files from the shipping executable directory, uses Windows wide paths, returns regular Lua file handles, and leaves process CWD alone. The canonical reader uses normal Lua `io.open` when the host function is absent. Keep the existing `SparkingZeroAccess-subtitles.ini` and `AE_debug` directory out of the package. [Lua 5.4 file handles](https://www.lua.org/manual/5.4/manual.html#luaL_Stream)

Do not copy UE4SS loaders, game proxy DLLs, UTOC bypasses, the old UniversalSpeech bridge, local configuration, game binaries, save files, captures, or research artifacts into the Reloaded II package. The existing narration WAV files are runtime mod assets and belong with the bridge. The F9 voiced-only behavior remains a separate task from this port.

The 359 Lua assertions across 35 original suites verify reader logic against fixtures. The owned-file regression checks the native-path dispatch of F5/F9. The compiled native file test exercises a Unicode game path, correct paths and file modes, and graceful failure when a file occupies `AE_debug`. Native audio tests exercise WAV operations outside the game. Live focus, state transitions, all battle/HUD sides, and narration synchronization still need in-process and listening evidence.
