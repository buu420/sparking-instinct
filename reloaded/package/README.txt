Sparking Instinct for DRAGON BALL: Sparking! ZERO, version 0.1.2 beta

Original Sparking Zero Access reader by Jessica Tegner and contributors.
The Reloaded II and Prism port is maintained by Buu420.

This package targets the 64-bit Steam game build 24953175, version
3022.021.003.012.015. Check menu speech, the controls list, training
prompts, battle gauges, story pages, and movie descriptions in your own
game before relying on the preview.

1. Install the Microsoft .NET 9 Desktop Runtime (x64) if prompted.
   https://dotnet.microsoft.com/download/dotnet/9.0
2. Close Sparking! ZERO and extract the complete ZIP.
3. If you installed a standalone Reloaded II preview, run Uninstall.cmd first.
   You can use the uninstaller from this ZIP for either older preview.
4. Run Install.cmd. It locates the game through Steam or opens a file picker.
   Setup downloads the original reader and narration from AccessForge and
   prepares them locally. Internet access is required.
5. Launch Sparking! ZERO from Steam or your usual desktop shortcut.

The installer suspends a matching, unshared Candidate 22 installation
and keeps its original files for rollback. If the startup path belongs to
another mod or loader, the installer leaves it in place and reports the
conflict.

Press F6 to read the screen. F7 and F8 review the previous and next item.
F9 toggles automatic subtitle speech. The saved preference, existing
narration and hotkeys carry over. F9 still covers automatic subtitles broadly.

For bug reports, look in SparkingZeroAccess-Reloaded\Logs for
SparkingZeroAccess.Reloaded.log and the startup log. The game's reader
diagnostic hotkeys use SparkingZERO\Binaries\Win64\AE_debug.

To uninstall, close the game and run Uninstall.cmd from the extracted ZIP
or the installed SparkingZeroAccess-Reloaded folder. It removes matching
package files and restores the verified legacy loader and registration
when safe. It preserves saves, preferences, logs, changed files, and
other mods.

Credits and corresponding loader source are under the installed LICENSES folder.
Use Amethyst for removal if you installed the mod through that manager.
